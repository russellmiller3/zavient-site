RPA vs agentic automation: which does your ops workflow need?

Bottom line
  • Use RPA if the steps are fixed, high-volume and run on stable screens, especially old apps with no API.46,26
  • Use an agent if the work means reading messy documents or making judgment calls, and a person checks the result.27,17
  • Use both if documents feed a system: the agent reads and decides, the bot executes, people approve exceptions.17,6
  • Use neither if the app has an API, the process keeps changing, or volume is too low to pay back.46,42
  • Either way, people approve payments and exceptions; an agent can't be held responsible for a mistake.38,27

What is the real difference?

An RPA bot repeats a fixed script exactly, while an AI agent picks its next step from the input, so its path can vary.16,43 Agents handle messy documents and judgment calls; bots are steadier on stable screens with fixed steps.27,46,42

How do RPA bots and AI agents differ in practice?

An RPA bot follows a fixed script on an app's screen, while an AI agent reads the input and picks its next step, so its path can differ.46,43,16

RPA means robotic process automation: software robots that work an app's screen the way a person does.46 An API is a direct data link between systems, with no screen involved.46 Gartner's one-line split: agents where decisions are needed, automation for routine workflows.26

Which one fits your team?

Invoice keying into an old system fits both, messy document intake fits an agent that reads and a bot that writes, and stable reconciliation fits a bot or API.10,6,46

1. Small AP (accounts payable) or ops team on Microsoft 365: invoices into an old system (both)

A team keying PDF invoices into a finance system (ERP) with no API. From 1 Nov 2026, new Microsoft licences carry no seeded AI Builder credits, so page reading draws Copilot Credits.15,13

  1. Ops leadTime today's keying and count errors for two weeks, as the baseline to beat
  2. AP clerkSave incoming invoices to one shared folder
  3. AI document stepPull vendor, PO (purchase order) number and amounts from each page13
  4. Unattended desktop botKey matched invoices into the finance system10
  5. ControllerApprove every mismatch in a built-in approval step before it posts16,38
  6. Ops leadCheck the run log and the mismatch rate each week40
  7. Ops leadRun it on one team's invoices for a month before adding others

Cost: A bot is $150 a month paid yearly, or $3.00 per unattended run, read 26 Nov 2026.10,11 Reading a page costs 8 credits, about $0.08, so 1,300 pages a month is about $104 (our arithmetic).13,14

2. Mid-size, document-heavy intake: claims, orders or onboarding (agent reads, bot writes)

Mixed documents arrive in many formats and someone has to judge what each one is. All three platforms document this agent-plus-robot pattern.6,17,25

  1. AgentSort each document and pull the fields the case needs6,25
  2. BotWrite the checked fields into your main system, such as the claims, order or HR system6
  3. Intake or claims leadApprove every case above a set amount, as a fixed human step8
  4. Named reviewerClear the agent's unclear cases from an escalation queue7
  5. Ops leadReview error and escalation rates monthly, and whether each step still pays40

Cost: UiPath bills 0.2 Platform Units per standard model call; its only public unit price is £900 per 1,000, UK public-sector list.2,4 Automation Anywhere charges 20 AI Credits per agent run, read 26 Nov 2026.22

3. Stable, high-volume reconciliation or data moves (bot or API only)

The task has one right answer and the screens rarely change. Gartner says agents are far less suited where only one correct answer exists.27,16

  1. ControllerWrite the matching rules and the tolerance for each account
  2. AnalystBuild an API flow where one exists, or an unattended bot where it doesn't46,10
  3. BotMatch items and send breaks to an exceptions queue
  4. AccountantClear every break and note the reason
  5. ControllerSign off the reconciliation; a second person moves bot changes to production40

Cost: A Power Automate bot is $150 a month, paid yearly, read 26 Nov 2026.10 Each bot runs one flow at a time, so parallel runs need more bots.10

Where does your team stay in charge?

Your people keep control: the controller approves every payment an agent drafts, the ops lead owns exceptions, builder and approver stay separate, and each automation has one named owner.38,7,40,27

  • Controller or AP lead: approves every payment an agent drafts. Microsoft's own guidance has AI draft the payment and a manager approve it.38,37
  • Ops lead: owns the exception queue. Unclear cases go to a named person or group, never to whoever is free by default.7,8
  • Bot builder and approver are different people: one builds or changes a bot, another moves it to production.40,41 Keep a bot inventory; Microsoft's audit log records flow changes, not each run.18
  • One named owner per automation: agents can't be held responsible, and a tribunal held Air Canada liable for its chatbot's answer.27,35

What do teams get wrong when they choose?

Teams go wrong by buying rebranded bots as agents, trusting one good demo, putting bots on unstable screens, giving agents ungated write access, and ignoring metered costs.26,30,29,37,2

  • Buying rebranded bots as agents: Gartner calls this agent washing and counts about 130 real agentic vendors among thousands.26 Ask for a demo where different inputs take different paths.
  • Trusting one good demo: agents vary from run to run, and complex screen workflows scored 9-19% in a UiPath researchers' test.30,9 Run 20-50 of your real cases several times and measure consistency.
  • Putting a bot on an unstable screen: 45% of firms dealt with broken bots weekly or more, in a vendor-paid 2020 survey.29 Use an API where one exists, and budget for upkeep.42,40
  • Giving an agent write access with no gate: one agent reportedly deleted a production database during a code freeze.36,34 Give agents accounts that reach only what the task needs and human approval before money moves or records change.37,38
  • Not counting metered costs: agents bill per call, credit or run, and Gartner names rising costs as a top reason projects get cancelled.2,13,26 Log calls per run in the trial and set spend alerts.
  • Assuming the vendor owns the mistake: a tribunal held Air Canada liable for its chatbot's wrong answer.35 Name one human owner for each automation before go-live.27,39

Questions buyers ask before they choose

Is RPA dead?

No: Gartner still says to use automation for routine workflows and agents where decisions are needed.26 UiPath, Microsoft and Automation Anywhere all still sell robots, now next to agents.1,10,21

Does agentic AI replace RPA?

Not for stable, rule-based steps, because Gartner says agents are far less suited where only one correct answer exists.27 Vendors now run bots and agents together in one flow.6,17

Can RPA bots and AI agents work together?

Yes, and it's the pattern all three big vendors document. Microsoft describes workflows that call agents and agents that use workflows as tools.17,6,25

What is the difference between an AI agent and an RPA bot?

An RPA bot runs the same fixed steps every time, while an AI agent decides its next step from the input.16,43 So a bot gives the same output for the same input, but an agent handles messy work and can vary between runs.16,30

Where does an agent earn its keep over plain RPA?

On messy inputs and judgment steps, with a narrow list of allowed actions.17,27

How much does an AI agent cost to run compared with a bot?

A bot is a flat fee, about $150 a month on Power Automate.10 An agent is metered, about $0.04-$0.05 per action in Copilot Studio by our math.13,14 Agent cost rises with every action, so at pay-as-you-go rates 3,000 actions a month cost the same as one bot.10,13,14

Should you buy a tool or build your own?

Buy: Buy a platform when the process is standard and you have no automation team.44,45 Menlo Ventures found 76% of enterprise AI use cases were bought in 2025, up from 53% in 2024.44 MIT NANDA found bought tools reached deployment about twice as often, from 52 interviews, correlation only.45

Build: Build your own flows on a platform when your rules and data are the edge and you need control of each step.16,3 All three let you bring your own model, which moves token costs to your model provider.2,23 For old systems, Gartner says redesigning the workflow often beats bolting on agents.26

When should you pick neither?

Pick neither when the app has an API, the process keeps changing, volume is too low to pay back, or one person just needs a lookup or summary.46,26,40

  • The app has an API or a built-in connector: use a cloud flow, not a screen bot.46,11 Zapier says RPA mostly remains for old systems without APIs (a vendor's view).46
  • The process is broken or keeps changing: fix it first. Gartner advises rethinking the workflow, and unstable processes eat bot returns in upkeep.26,42
  • Volume is too low to pay back: keep it manual and review it yearly. COSO says to check regularly whether a bot adds measurable value.40,42
  • One person needs a lookup or a summary: use an AI assistant, not an agent or a bot. Gartner reserves assistants for simple retrieval.26
